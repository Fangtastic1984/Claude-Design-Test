# Toekomsrus Hub v2

Community marketplace platform for Toekomsrus, Randfontein — taskboard for local needs and
offerings, promotional banners, and food ordering with three-wheeler delivery, delivered as
an installable PWA.

**Current status:** specification phase. See [SPEC.md](SPEC.md) for the full technical
specification (data model, flows, state machines, build phases). No application code yet —
the spec is awaiting sign-off before phase 1 (Foundation) begins.
